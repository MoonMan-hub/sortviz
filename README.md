# SortViz

Практическое задание «Системы сборки».

## Суть проекта

SortViz — веб-приложение для наглядной демонстрации работы алгоритмов сортировки: пузырьковой, быстрой и сортировки слиянием. Java-сервер (Spring Boot) сортирует массив и записывает последовательность операций — сравнений, обменов и записей. Браузер воспроизводит эти операции на столбчатой диаграмме по шагам или целиком.

Можно ввести от 2 до 100 целых чисел вручную, загрузить их из файла UTF-8 с расширением `.txt` или `.csv` либо сгенерировать случайный массив. Доступны выбор порядка (по возрастанию / по убыванию) и опорного элемента для быстрой сортировки. Отрицательные числа отображаются ниже нулевой линии. Измеренное время включает запись шагов на сервере.

### Структура проекта

| Путь | Назначение |
| --- | --- |
| `pom.xml` | Файл сборки Maven |
| `src/main/java/ru/sortviz/` | Точка входа `SortVizApplication` |
| `…/algorithm/` | Три алгоритма и запись операций (`SortTrace`) |
| `…/model/` | Параметры запроса, шаги и результат сортировки |
| `…/service/` | Проверка данных и запуск выбранного алгоритма |
| `…/web/` | REST-контроллер `POST /api/sort` |
| `src/main/resources/` | Настройки сервера и веб-интерфейс в `static/` |
| `src/test/java/` | Тесты результата сортировки и воспроизведения шагов |
| `target/` | Результаты сборки (создаётся Maven, в репозиторий не входит) |

## Сборка

Требуются JDK 17 или новее и Apache Maven 3.6.3 или новее. При первой сборке нужен доступ к Maven Central для загрузки зависимостей.

В корне проекта выполните:

```bash
mvn clean package
```

Команда удаляет результаты предыдущей сборки, компилирует код, запускает тесты и формирует исполняемый JAR `target/sortviz-1.0.0.jar`. Плагин Spring Boot (цель `repackage`) упаковывает в него все зависимости и загрузчик.

Основные настройки `pom.xml`:

- координаты: `ru.sortviz:sortviz:1.0.0`;
- версия Java: 17 (`java.version`);
- точка входа: `ru.sortviz.SortVizApplication` (`mainClass` в `spring-boot-maven-plugin`).

Только тесты: `mvn test`.

## Пример запуска

```bash
java -jar target/sortviz-1.0.0.jar
```

После запуска откройте в браузере <http://127.0.0.1:8080/>, выберите алгоритм и нажмите «Запустить» либо «Шаг вперёд».

Сервер также можно вызвать напрямую:

```bash
curl -X POST http://127.0.0.1:8080/api/sort \
  -H "Content-Type: application/json" \
  -d '{"data":[5,3,8,1],"algorithm":"QUICK","order":"ASC","pivot":"MIDDLE"}'
```

В ответе — отсортированный массив, список шагов и метрики.

Завершить работу сервера — `Ctrl+C` в терминале. Если порт 8080 занят, запустите с другим портом и откройте <http://127.0.0.1:8081/>:

```bash
java -jar target/sortviz-1.0.0.jar --server.port=8081
```
